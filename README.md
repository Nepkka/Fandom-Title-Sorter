# FandomTitleSorter

Локальный сортировщик артов по фандомам, авторам и персонажам.

## Требования

- Python 3.15+
- Node.js и npm
- Google Chrome

## Установка

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Запуск

```powershell
.\venv\Scripts\python.exe desktop.py
```

## Лимиты поисковиков

| Сервис | Лимит |
|---|---|
| SauceNAO | 6 картинок в минуту и 100 в сутки на IP; без ключей 20 в сутки |
| IQDB | 5–9 картинок в минуту |
| trace.moe | 100 кадров в сутки на IP |
